# Code of Conduct

We follow the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Be respectful and constructive; critique code, not people.
- No harassment, discrimination, or personal attacks.
- Assume good faith; help newcomers.

Maintainers may remove comments, commits or contributors that violate this. Report concerns privately via GitHub's *Security → Report a vulnerability* flow or by contacting the maintainer through their GitHub profile.
